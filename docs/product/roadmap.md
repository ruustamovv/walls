# Product roadmap (narrative companion to ROADMAP.md)

## Vision
The home ground for wall-and-pawn strategy: instant to learn, lifetime to
master, fair by construction (server-authoritative, open engine rules).

## Staged bets
1. **Prove the duel (Phases 00–08).** Deterministic engine, fair realtime,
   crisp board UX. Success = 2-player live game with clocks works on
   mobile + desktop.
2. **Give it depth (09–13).** Bots, AI coaching, replays, tournaments,
   seasons. Success = a solo player can improve weekly without queuing.
3. **Grow the scene (14–19).** Social graph, admin/mod tooling, payments,
   mail, media. Success = clubs run their own events with platform prizes.
4. **Harden & launch (20–28).** Observability → security → legal → beta.
   Success = SLO-backed open beta with on-call and cost control.
5. **Explore V2 (29).** Variants and mobile behind flags; only what the
   corpus + feedback justify.

## Non-goals (v1)
4-player chaos as default, real-money wagering, opaque matchmaking,
marketing-led feature bloat. Performance budget: first paint < 1.5 s on
mid-tier mobile; move patch client→client p95 < 250 ms regionally.
